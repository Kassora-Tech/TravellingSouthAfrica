# **App Name**: Travelling South Africa Reborn

## Core Features:

- Homepage Hero Animation: Animate the text of the logo upon homepage load using a handwriting/drawing effect.
- Province Pages: Display detailed information on South Africa's nine provinces with high-quality images and key details. Pulls the information from the Firestore.
- Town Pages: Create individual pages for 862 towns with detailed information and relevant links. The information about each town is saved on Firestore.
- Sights to See Listings: List and detail various sights to see throughout South Africa, optimized for visual appeal and information. The information is saved in Firestore.
- Plan Your Trip: Allow users to register/login to plan their trips.
- Currency Converter: Implement a tool to convert currencies to help travelers.
- Bilingual Support: Implement a language switcher to toggle between English and Afrikaans content. Use generative AI tool to translate between the languages.

## Style Guidelines:

- Primary color: Deep sky blue (#00BFFF), evoking the vast South African skies, inspired by the flag's vibrant hues.
- Background color: A very light gray (#F0F0F0) provides a clean and spacious feel, allowing content to stand out.
- Accent color: Golden yellow (#FFD700), analogous to the primary color, offering a contrasting highlight that symbolizes the country's wealth and sunshine.
- Body font: 'Inter', a sans-serif font known for its readability and modern appearance. Headline font: 'Playfair', a modern serif font which adds a touch of elegance.
- Use clean, minimalist icons representing locations, travel tools, and other relevant elements.
- Employ a card-based layout with generous white space for a clean, modern, and responsive design.
- Implement smooth transitions and subtle animations on UI elements to enhance user experience and engagement.
